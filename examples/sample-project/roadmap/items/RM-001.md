# RM-001 — Workspace invitations

## User story

As a workspace admin, I want to invite teammates and choose their roles, so that I can onboard my team without support.

## Acceptance criteria

- [x] An admin can invite a valid email address.
- [x] The admin can select a workspace role.
- [x] An invitation expires and can be accepted only once.
- [x] Invitation events appear in the audit trail.
